# 魔法源语言参考

这是 `runeing` 的源语言。读者照着本文即可写出咒语，编译器按本文描述给出结果。

---

## 1. 快速开始

新建 `my.rune`：

```
光射线 : 光 = 发光 → 点 → 发射 → 发射
```

编译：

```bash
python3 examples/compile.py my.rune
```

输出：

```
[解析] 咒语 光射线，4 个魔文
[信息] C_OK: 容量 4/10：常态
[信息] C_ELEMENT: 元素 光：有实例
[IR] IR(kind='projectile', element='光', create=('发光', '点'), emit=('发射', '发射'))
[求值] Value(element='光', form='projectile')
```

四行分别对应四个阶段：**解析 → 检查 → 降级 → 求值**。

## 2. 语法

### 2.1 形式

```
名字 : 元素 = 魔文 → 魔文 → …
```

| 部分 | 说明 |
|---|---|
| `名字` | 咒语名，不含空格、`:`、`=`、`#` |
| `元素` | 光 / 冰 / 火 / 金 / 风 / 木 / 水 / 土 |
| `→` | 连笔方向：前一个魔文的末尾连到下一个魔文的开头 |
| `魔文 × N` | 该魔文重复 N 次 |

### 2.2 为什么用箭头

第 16 章原文：

> 从一个魔文的**末尾**连接另一个魔文的**开头**，将它们连接成一个整体

`→` 就是这句话的形状。不用括号、不用分号，因为施法本来就是一条有向序列。

### 2.3 注释与空行

```
# 这是注释
光射线 : 光 = 发光 → 点 → 发射 → 发射
```

`#` 之后整行忽略。一个文件只放一个咒语。

### 2.4 源码里没有连笔

连笔是 (魔文对 × 魔女) 的私有表（第 17 章：每一位魔女所使用的连笔也与别的魔女不同）。
所以它不属于源码，由施法者补。源码只描述**哪些魔文、什么顺序**。

## 3. 编译器做什么

| 阶段 | 输入 | 输出 | 失败时 |
|---|---|---|---|
| 解析 | 文本 | `SpellSource{name, element, runes}` | `ParseError` |
| 检查 | `SpellSource` | `Diagnostic` 列表 | 有“错误”则终止 |
| 降级 | `SpellSource` | `IR{kind, element, create, emit}` | —— |
| 求值 | `IR` | `Value{element, form}` | —— |

### 3.1 容量判定

| 魔文数 | 结论 | 依据 |
|---|---|---|
| ≤ 10 | 常态 | 第 44 章“我平时也就容纳十个魔文”（上界，单调） |
| 13 | 可成型，约一秒后崩溃 | 第 58 章实测 |
| 15 | 失败 | 第 44 章“十五个魔文根本稳定不住” |
| 11 / 12 / 14 | **无法判定** | 未采样，不内插 |

### 3.2 元素判定

| 状态 | 元素 | 结果 |
|---|---|---|
| 有实例 | 光 冰 火 金 风 木 | 通过 |
| 仅提及 | 水 土 | 警告 |
| 未出现 | 雷 暗 | 错误 |

### 3.3 结构识别

4 个魔文且后两位是 `发射` 时，识别为投射模板：

```
Projectile<E> = create_E(2) + emit(2)
```

否则降级为 `generic`，只保留魔文序列，不做结构判断。

## 4. 诊断码

| 码 | 级别 | 含义 |
|---|---|---|
| `C_OK` | 信息 | 容量在常态范围内 |
| `C_ELEMENT` | 信息 | 元素有实例 |
| `W_CAPACITY` | 警告 | 容量处于边缘或未采样 |
| `W_ELEMENT` | 警告 | 元素仅一句“同理”提及 |
| `E_CAPACITY` | 错误 | 容量超限，无法稳定成型 |
| `E_ELEMENT` | 错误 | 元素在原文中未出现 |

有 `E_` 前缀时，编译器终止，不生成 IR，退出码 1。

## 6. 限制

| 限制 | 原因 |
|---|---|
| 只支持一环 | 二环只有五彩光球一个样本，且内环数出自疑问句 |
| 不支持连笔语法 | 连笔是私有的，不是源码的一部分 |
| 只识别投射模板 | 其余结构降级为 `generic`，不做语义判断 |
| 求值只到 `(元素, 形态)` | “发射”没有可计算的定义 |
| 一个文件一个咒语 | 最小实现，可扩展 |

**这些限制不是遗漏，是语料边界。** 原文没写的东西，编译器不猜。
